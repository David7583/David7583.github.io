02 / ENGINEERING METHOD

不止是结果。
也关心结果从何而来。Beyond the output.
Back to the evidence.

这些项目共享同一个问题：怎样让系统的行为更清楚、更可控、更容易检查？A shared question across these projects: how can a system’s behavior become clearer, more controlled and easier to inspect?

01

保留来源Preserve the source

+

原始数据与派生结果分开；结论能够定位到依据。Keep source data separate from derived results; make evidence locatable.

02

明确契约Define the contract

+

用结构化输入、输出与约束，减少隐含假设。Reduce implicit assumptions through structured inputs, outputs and constraints.

03

限制行动Bound the action

+

加载、连接与执行分别管理，写入需要明确授权。Manage loading, connections and execution separately; require authorization for writes.

04

留下证据Leave a trace

+

保留版本、运行状态和错误，让下一次改进有据可依。Record versions, run state and errors so the next iteration has evidence.
