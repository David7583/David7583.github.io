核心项目

01 / CORE

SC‑TSE

面向场地布局的确定性计算与校验系统。它接收结构化场地、体块和约束，运行布局、连通性、道路与出入口检查，并把通过、阻断与具体违规证据返回给使用者。

结构化 JSON 输入 六节点计算主链 约束证据回传
查看 GitHub↗

范围说明：公开仓库是 Integration MVP，当前支持固定矩形体块的编辑、重算与校验；地形、挖填方、自动布局和空间内核截图展示的是同一研发方向下的更广泛实验结果，不代表公开 MVP 已包含这些界面或全部能力。

02 / CORE

Yuantu 源图

为政策文档、访谈记录等长期积累的非结构化文本建立可追溯知识层。原始材料保持不变，SQLite、ChromaDB、DuckDB 与 Neo4j 分别负责定位、语义、事实和关系检索，让结论能够回到原始证据。

解决的问题：大型模型直接检索长年累积材料时，答案容易失去来源。Yuantu 先定位文本单元，再从语义、事实和关系三个独立维度补充证据，并记录每一步运行信息。

查看 GitHub↗

范围说明：Yuantu 是研究原型，公开仓库完成了四数据库理解层，行动层仍在开发；上图是相关系统观察界面，不是仓库内发布的产品 UI。

03 / CORE

Baigong 百工

一个本地 Data–Action–Data 演示链路，用于验证 AI 在读取数据、调用能力和写回结果时，输入来自哪里、哪一版本执行、哪些动作获准，以及失败后如何定位。

实际输出：稳定对象 ID、来源路径和内容哈希；每次运行的 run ID、版本与完成清单；对数据库写入、真实模型调用等动作设置显式确认门，并用结构化错误保留失败证据。

查看 GitHub↗

范围说明：公开仓库是可独立安装测试的治理链路 Demo，不是通用 Agent 产品；上图为相关交互原型，不是 Baigong 发布包中的正式界面。
